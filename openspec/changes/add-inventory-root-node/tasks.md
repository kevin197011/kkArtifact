- [x] 1.4 为根节点设置合适的图标与样式（与项目节点区分），保持与现有 `InventoryPage.module.css` 风格一致。
- [x] 1.5 无数据（空列表）时不渲染根节点或保持现有空状态展示，不出现仅有根节点无子节点时的误导展示。
