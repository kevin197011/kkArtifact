# Change: 首页项目树增加根节点以支持一键折叠所有项目

## Why

首页（制品清单页）当前树形结构直接以多个项目为顶层节点展示，项目较多时无法通过单一操作折叠整棵树。增加一个根节点后，用户可点击根节点展开/折叠，一次性收起或展开所有项目，提升浏览与导航体验。

## What Changes

- 在首页（`/`）的制品清单树中增加一个虚拟根节点（例如「全部项目」或「项目」）。
- 当前所有项目节点作为该根节点的子节点展示。
- 根节点支持展开/折叠；折叠时整棵树收起，展开时显示所有项目（保持现有项目→应用→版本的层级与交互）。
- 搜索、筛选、空状态等现有行为不变；有数据时树根始终为该根节点。

## Impact

- Affected specs: artifact-web-ui
- Affected code: `web-ui/src/pages/InventoryPage.tsx`（树数据构造与 `Tree` 的 `treeData`/`expandedKeys` 逻辑）
